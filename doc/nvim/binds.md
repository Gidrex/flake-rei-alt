## Core

- `Alt+w` — save file
- `Alt+q` — quit
- `Z` — LazyGit (floating window); `ZZ` / `ZQ` are disabled

## Space menu (leader = space)

- `Space f` — file picker
- `Space b` — buffers
- `Space g` — git status
- `Space /` — live grep
- `Space d` — diagnostics
- `Space x` — diagnostics list (Trouble)
- `Space y` — yazi picker
- `Space q` — calculator (qalc)
- `Space a` — outline (Aerial)
- `Space Space` — reload buffer
- `Space c` — code action
- `Space r` — rename symbol
- `Space D` — go to definition
- `Space h` — hover docs
- `Space F` — format buffer
- `Space i` — toggle inlay hints

## Git review (Space G)

- `Space G s` — stage hunk
- `Space G r` — reset hunk
- `Space G p` — preview hunk
- `Space G b` — blame line
- `Space G d` — diff current buffer
- `Space G D` — side-by-side diff (Diffview)
- `Space G l` — file history (Diffview)
- `]c` / `[c` — next / prev hunk

## AI completion (minuet, Muse Spark)

- suggestions appear in the blink menu while typing
- `Alt+y` (insert mode) — invoke manually

## Surround / comment

- `m s` — add surround
- `m d` — delete surround
- `m r` — replace surround
- `g c` — toggle comment
- brackets and quotes auto-close; enhanced `i` / `a` textobjects

## Outline (Aerial)

- `{` / `}` — prev / next symbol

## Debug (DAP)

- `F5` — continue / start
- `F10` — step over
- `F11` — step into
- `F12` — step out
- `Space B b` — toggle breakpoint
- `Space B c` — conditional breakpoint
- `Space B r` — REPL
- `Space B u` — debug UI
- `Space B t` — terminate session
